# 🎯 Number Guessing Game

### OASIS INFOBYTE – Java Development Internship | Task 2

A console-based **Number Guessing Game** developed using **Java and Object-Oriented Programming (OOP)** concepts.

The computer generates a random number, and the player has to guess the number within a limited number of attempts. The game provides hints such as **Too High**, **Too Low**, and **Correct**.

---

## 📌 Project Objective

The objective of this project is to develop an interactive Number Guessing Game using Core Java.

The application allows the player to:

- Select a difficulty level
- Guess a randomly generated number
- Receive Too High / Too Low hints
- Track attempts
- Earn scores
- Play multiple rounds
- View game history
- View final game statistics

---

## 🚀 Features

- 🎲 Random number generation
