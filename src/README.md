# 🎯 Number Guessing Game

## OASIS INFOBYTE Java Development Internship – Task 2

A console-based Number Guessing Game developed using **Core Java and Object-Oriented Programming (OOP)** concepts.

The computer generates a random number, and the player has to guess the number within a limited number of attempts. The game provides hints such as **Too High**, **Too Low**, and **Correct**.

---

## 📌 Project Objective

The objective of this project is to build an interactive Number Guessing Game using Java.

The game allows the player to:

- Select a difficulty level
- Guess a randomly generated number
- Receive higher/lower hints
- Track the number of attempts
- Earn scores
- Play multiple rounds
- View game history and statistics

---

## 🚀 Features

- 🎲 Random number generation
- 🎮 Three difficulty levels
- 🔢 Limited number of attempts
- ⬆️ Too High hint
- ⬇️ Too Low hint
- ✅ Correct guess detection
- ⚠️ Invalid range validation
- 🔁 Duplicate guess detection
- 🏆 Score calculation
- 🔄 Multiple rounds
- 📊 Win/Loss statistics
- 📜 Round history
- 🥇 Best score tracking
- ▶️ Play Again option
