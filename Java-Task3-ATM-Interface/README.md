\# 🏦 ATM Interface



\### OASIS INFOBYTE – Java Development Internship | Task 3



A console-based \*\*ATM Interface\*\* developed using \*\*Java and Object-Oriented Programming (OOP)\*\* concepts.



This project simulates basic ATM operations such as user authentication, cash withdrawal, deposit, money transfer, and transaction history.



\---



\## 📌 Features



\- 🔐 User Login with User ID and PIN

\- 💰 Check Transaction History

\- 💸 Withdraw Money

\- 💵 Deposit Money

\- 🔄 Transfer Money

\- 📋 View Current Balance

\- 🚫 Insufficient Funds Validation

\- 🔒 Maximum 3 Login Attempts

\- ❌ Quit ATM Safely



\---



\## 🛠️ Technologies Used



\- \*\*Java\*\*

\- \*\*Object-Oriented Programming (OOP)\*\*

\- \*\*Java Collections\*\*

\- \*\*Java Scanner\*\*

\- \*\*LocalDateTime\*\*
